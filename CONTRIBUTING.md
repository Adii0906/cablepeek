# Contributing

Small, focused pull requests are easiest to review. For a larger idea, please open an issue first.

- Build with `./build.sh`, then compare `CablePeek.app/Contents/MacOS/CablePeek --dump` before and after your change.
- Say which Mac and macOS version you tested on, and what you could not test.
- CablePeek only reads. No network access, no files, no dependencies, and ejecting is never forced.
- Texts need German and English, through `L(de, en)`.
